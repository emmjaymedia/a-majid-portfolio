A Microsoft 365 MFA lockout and “something is broken” both land in the same IT inbox. They need different next steps.

I built an IT support triage workflow with n8n, the OpenAI API, and Google Sheets. The model reads the request and returns a category, urgency, and short summary. Rules in n8n decide which queue gets the ticket and flag ambiguous requests or urgent impact for human review.

In the walkthrough, an MFA lockout goes to Identity. A request with too little detail goes to the Service Desk for review.
